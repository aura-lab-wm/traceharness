# Execution, Grading, Accounting & Performance Verification Plan

## 1. Scope & Non-Negotiable Guardrails
- **Authority & Minimum Scope**: Root owns live credentials, host deployment, image registration, and paid execution. No provider API keys exist in source, manifests, logs, or CLI arguments. Ambiguous or historical jobs (including experiment `21b348521cffbbf46c49aaa595e205bdc2b2ad412d672eef`) are **never retried, mutated, or purged** to clear state; `data/runs` and task/grader check definitions remain untouched.
- **Preserved Boundaries**: Retain numeric caps (`max_steps`, `wall_time_seconds`, `max_cost_usd`, `max_output_tokens`), digest-pinned runtime/grader images, exact task/runtime/model compatibility receipts, offline `--network none` hidden grading (`UID 0` writer / `UID 10002` isolated candidate, no hidden check leakage to task containers), Worker HMAC/session/hostile-Origin (`403`)/anonymous (`401`, no `Access-Control-Allow-Origin`) gates, per-job tmpfs/container cleanup barriers, immutable `manifest_sha256`, and relative imports compatible with `harnesslab` control-image overlays.
- **Accounting & Anti-Masking Rule**: Never lower conservative pre-call reservations below true worst-case exposure or inflate caps merely to hide defects. Never coerce an unknown charge to `$0.00` if **any** provider request was issued (`requests > 0` without complete terminal usage) or if transport outcome was uncertain (`transport_failed`). Zero automatic billable retries (`retries=1`, `request_max_retries=0`).

## 2. Root-Cause Audit of Experiment `21b348521cffbbf46c49aaa595e205bdc2b2ad412d672eef`
Historical baseline (`4` cells, `$0.01` cap/cell, `4` steps, `512` max output tokens): `1` passed; `2` stopped after 1–2 responses (`~$0.0094` next conservative reservation exceeded remaining `$0.01` cap, with actual costs reported on completed calls) leaving useful `patch.diff` artifacts `ungraded`; `1` failed at `requests=0` after premature credential revocation with cost omitted/unknown.

1. **Configuration constraint C1 — Tight `$0.01` Cap vs Conservative Byte + Output Reservation (`intended reservation enforcement`; `usage.include` hypothesis `REJECTED`)**:
   - **Actual cause (`PROVEN`)**: `jobs.py:515` reserves `(len(canonical(body)) + 8192) * prompt_price + maximum_output * completion_price + request_price`. With `include_file_listing=True` (`harness.py:136-137`), tool schemas, and step 1–2 file/test observations, the next conservative reservation reached `~$0.0094`, exceeding the remaining allowance of the `$0.01` cap after 1–2 settled responses (`jobs.py:519-527`).
   - **Rejected hypothesis (`REJECTED — do NOT implement`)**: An earlier static hypothesis blamed `providers.py:173,196` omitting `usage.include` over the localhost proxy. Under official OpenRouter usage-accounting docs (`https://openrouter.ai/docs/cookbook/administration/usage-accounting`), usage and cost reporting are **automatic**, `usage.include` and `stream_options.include_usage` are **deprecated no-ops**, and actual costs were already reported on completed calls. Do **not** add those deprecated flags.
2. **Defect D2 — Candidate Workspace Left `ungraded` & Excluded After Ordinary Stopped Execution (`PROVEN`)**:
   - Broker budget/step refusal returns HTTP `502` (`proxy.py:53-56`) -> `_post_json` raises `RuntimeError` (`providers.py:139-145`) -> `harness.run_task` sets `exit_reason = "error"` (`harness.py:279-281`) while writing `patch.diff` (`harness.py:285-288`) -> `container_entrypoint.py:172` returns exit `1`.
   - `DockerExecutor._run` raised `ExecutionError` (`execution.py:197-198`) before launching the offline grader (`execution.py:373-388`), leaving `grade="ungraded"` (`jobs.py:386,595`). Furthermore, `experiments.summarize` (`experiments.py:165-167`) previously required `status == "succeeded"`, discarding trusted `passed`/`failed` grades when `trial` and `job` finished in ordinary `failed` state. `summarize()` now counts `passed`/`failed` grades iff both `trial.status` and `job.status` are in `{"succeeded", "failed"}` (excluding `cancelled`, `needs_attention`, active states, `ungraded`, and `error`).
3. **Defect D3 — Zero-Request Pre-Transport Failures Shown as Cost Unknown (`PROVEN by static trace`)**:
   - Initial `job.usage` is `{"requests": 0}` without `cost_usd` (`jobs.py:386`). When credentials were revoked (`service.py:284-289`) or pre-transport checks refused before `requests += 1` (`jobs.py:530`), zero provider calls were issued, yet `summarize()` (`experiments.py:149-156`) counted `reported(t) is None` under `cost_unknown_trials`. Only when `requests == 0` **and** `not transport_failed` is confirmed spend provably `$0.00` (`input_tokens=0, output_tokens=0, cost_usd=0.0`).

## 3. Static Performance Bottleneck Audit (Safe Repair Candidates)
