# Runner moved to TraceHarness 0.5.1 — 16 November 2026

The dedicated Fly runner (`traceharness-runner`) now runs TraceHarness **0.5.1** for its control service and all three runtime images. Execution is enabled on release **v21** with the same coverage as before: eight curated tasks and **19 verified task/runtime/model combinations**, each re-verified on the new images. Native-prompt editing for Claude Code and Codex is preserved, with both inventories regenerated for the new images. Exact identities are in [the evidence JSON](2026-11-16-v051-evidence.json).

## What changed

- The control service and the TraceHarness, Claude Code and Codex runtime images were rebuilt from the attested v0.5.1 wheel (the previous images still carried the pre-rename `harnesslab` 0.3.0 package). The recipe change is #27.
- Grader inputs were byte-identical to the previous release, so both existing grader images were reused unchanged.
- The Claude Code (2.1.322) and Codex (0.167.1) executables are byte-identical in the new images, and the native-prompt materializer and taxonomy hashes are unchanged. Only the base image digest changed. The Claude inventory was re-finalized from the same parsed candidates. The Codex preparer gained an explicit `--image-digest` argument (#28); with the old digest it reproduces the previous inventory byte for byte.

## Verification

- **Native prompts.** For each runtime, six offline captures ran on the VM's gVisor sandbox: the original binary, Keep, no-op Replace, marker Replace, single Disable and all-patchable Disable. They used the actual native CLI against a loopback fake API, and no provider was contacted. The comparisons passed and new mechanism receipts were issued.
- **Compatibility.** 19 operator runs (`verify_runtime.py`) used the previous receipts' caps, and all 19 succeeded with grade `passed`. Reported cost was $2.0357.
  - TraceHarness / GPT-4.1 Mini: 8 tasks, 4–5 requests each.
  - Codex / GPT-5.1 Codex Mini: 7 tasks, 8–14 requests.
  - Claude Code / Claude Haiku 4.5: 4 tasks, 8–14 requests, $0.35–0.62 each.
- **Member flow.** A signed-in member job (Claude Code, native-prompt marker profile, `requests-unicode-length`) succeeded and passed independent grading. It cost $0.3418 over 8 requests.
  - The replacement was observed in the emitted requests, and every artifact hash matched.
  - A hostile Origin was refused, and the transient credential was revoked.
  - An earlier attempt with a $0.35 cap stopped when the broker refused a request whose conservative reservation ($0.2168) exceeded the remaining allowance. Its workspace still graded `passed`. It is kept as a failed outcome, not retried silently.
- **Anonymous.** `prove-anon.py` exited 0. An unsigned direct request to the runner API returned 401.

## Deployment

1. **v18 failed.** The new control code refused the old registry's native-prompt inventory, which was still bound to the previous Codex image (`Native prompt inventory does not bind this runtime`), so the machine stopped after its restart limit.
2. **v19 rolled back.** It restored the v17 image and registry.
3. **v20 (execution disabled) and v21 (enabled).** Both run the 0.5.1 control service, using `/data/inventory-eight-v2/registry-v051.json`. The previous registry and inventories remain on the volume for rollback.
