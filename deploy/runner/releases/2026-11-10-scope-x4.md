## What changed

- Added pinned Unicode upload-length, leading-URL-slash and empty-netrc authentication tasks. Each packages the broken upstream revision, source/archive hashes, public reproduction, independent hidden checks and a disclosed narrow edit contract. The original JSON task package and hash remain unchanged.
- Bound compatibility receipts to the exact runtime/version/image, model, task/revision/content and grader image. Success on one task cannot enable another. Registry replacement preserves receipts for other combinations.
- Added per-task readiness maps and strict Worker validation, including rejection of invented models, duplicate pairs and contradictory availability.
- Extended the independent grader with three reviewed static edit contracts. Missing/unknown contracts fail closed; protected-file edits and forged-success output remain refused.
- Added explicit bounded operator limits. Claude defaults to 32 requests/$2; the other engines 20 requests/$1; all 240 seconds. No automatic paid retries.

## Failures preserved

1. The Unicode Claude member run failed after an OpenRouter HTTP402. It remains failed/ungraded; its provider-reported cost is absent, so the total cost of all attempts is **unknown**, not zero. OpenRouter documents 402 as a credit or in-flight budget refusal: [official limits](https://openrouter.ai/docs/api_reference/limits).
2. The initial netrc TraceHarness run reached 20 requests with no edits and failed grading. The 6,000-character observation limit cut off relevant source; the model repeatedly guessed unmatched edit text. One bounded retry kept the same prompt/model/task/images and 20-request/$1/240-second limits, while selecting 20,000 observation characters, 4,096 output tokens and temperature 0 through the existing UI. It passed in 4 requests. Both attempts remain in history.
3. A retry proof stopped before credentials or launch because JavaScript normalized compiled temperature 0.0 to 0. A real signed-in, read-only diagnostic confirmed semantic equality and the exact server hash after restoring the compiler-declared float. The proof now distinguishes raw artifact SHA from canonical manifest SHA and verifies both. No production hashing, image, receipt or original proof was changed to conceal the failure.
