## Installed task and scope

The runnable package is Requests issue #6628, pinned to source revision
`96b22fa18c00831656ee4b286bf1c9062459b00a`. It contains the real repository,
installed dependencies, visible reproduction tests and independent offline
checks. The deployed grader rejected the broken baseline, a previously observed
incorrect repair and forged success output, while accepting the upstream fix.

This release supports **one curated task and the three exact pairs above**.
The Requests package has a disclosed static edit contract: preserve the original
module and add only its reviewed serialization method. See the
[task policy and packaging instructions](../tasks/README.md). This is not arbitrary
repository upload, unrestricted source grading or verified support for every
OpenRouter model. Native tools retain their own execution loops; TraceHarness
blocks configure the TraceHarness engine.

The dedicated Fly VM uses gVisor task containers with no network, read-only root,
UID 10001, no capabilities, two CPUs, four GiB memory and 256 PIDs. Those restrictions
were checked on the actual host. Provider keys stay in service memory, expire
after an hour and disappear on restart. The JWT stays at the Worker. Jobs and
artifacts are retained for 24 hours. Current capacity is one worker and one active
job per member.
