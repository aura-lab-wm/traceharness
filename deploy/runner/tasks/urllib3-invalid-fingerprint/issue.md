# urllib3: normalize malformed TLS fingerprint errors

Upstream issue: https://github.com/urllib3/urllib3/issues/5211
Upstream merged fix: https://github.com/urllib3/urllib3/pull/5212
Baseline revision: 9a97e7b945c1d0286ffdbb5b876714b72aba0370

A supported-length certificate fingerprint containing non-hexadecimal characters leaks binascii.Error instead of the documented SSL error family. Normalize this parse failure to SSLError while preserving the underlying cause and existing valid fingerprints, digest mismatch, unsupported lengths and missing-certificate behavior. This is exception compatibility, not a certificate-validation bypass: malformed input already fails validation.

This is a real upstream issue packaged as a curated TraceHarness repair task, not a general benchmark or unrestricted repository-editing claim. Python 3.12 and the existing pinned dependencies suffice. All checks operate offline; no service, TLS connection, model key or credential file is needed. Both public and hidden checks verify that the imported package lives inside this exact candidate checkout.

Run the public reproduction:

    PYTHONPATH=src python -m unittest discover -s public_tests -v

The independent grader enforces TRACEHARNESS_TASK_POLICY.json before importing candidate code, then runs four behavioral checks. Preserve all original files except the one documented editable module; comments and formatting in that module may change, but unrelated AST changes are rejected. New workspace files are excluded from grading.

The protected src/urllib3/_version.py is deterministic build metadata supplied because upstream Git archives omit the file generated by hatch-vcs. Its 0.0.0+traceharness commit identifier is not an upstream release version. No installed urllib3 source is substituted.

Public edit contract: Only add `from binascii import Error as BinasciiError` immediately before the existing unhexlify import, or combine it as `from binascii import Error as BinasciiError, unhexlify`. In assert_fingerprint, wrap only the existing fingerprint_bytes = unhexlify(fingerprint.encode()) assignment in try/except BinasciiError. Name the caught exception e, error or exc; raise SSLError with that exception or str(exception), explicitly chained `from` the same exception. Preserve the rest of the entire module AST. No broad exception handler, validation bypass, alternate import or additional call is permitted.
