# urllib3: classify unseekable request-body retry failures

Upstream issue: https://github.com/urllib3/urllib3/issues/3779
Upstream merged fix: https://github.com/urllib3/urllib3/pull/3780
Baseline revision: 7a802a49bb7880624b5fa0053dd7cc77b94966c2

An upload body may support read and tell but omit seek. Retrying it with a correctly recorded integer position currently raises ValueError blaming that integer. Raise UnrewindableBodyError for the missing seek capability, while preserving successful seek behavior, failed tell/seek handling and invalid-position errors on seekable bodies. This improves error classification; it does not make an unseekable stream rewindable.
